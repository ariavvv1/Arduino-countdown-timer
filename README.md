# Arduino-countdown-timer
this is what hardware I used in this project
.LCD 16×2
.Arduino Nano
.5×push buttons
.5×10kΩ resistors
.one 330Ω resistor(you can also use 220Ω) for LCD backlight 
.one buzzer
.jumper wires
.one potentiometer 10KΩ for adjust the contrast of LCD   
this project is a regular and normal timer alarm you can use it to count seconds or minutes
it's simple but maybe useful for you 
the buttons left to right "Plus,minus,start/reset,minutes_mode,secounds_mode"
it's has some little bugs but I fixed 99% of other bugs and problems
and minute mode is very similar to seconds mode, only difference is in minute mode the value you input×60 to convert minutes to seconds, counting down section is from seconds mode to coding easily, you can change the code to optimize it or maybe some other reasons, Every now and then, I further optimize this code and fix its bugs.
